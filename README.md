# Personal Portfolio — Arya Sandesh Thakur

A responsive personal portfolio showcasing AI & Data Science engineering projects, technical skills, and credentials. Built with semantic HTML5, custom CSS3 glassmorphism styling, and vanilla JavaScript.

## 🛠️ Tech Stack
* **Frontend:** HTML5, CSS3, JavaScript (ES6+)
* **Icons & Fonts:** Font Awesome 6, Space Grotesk, Plus Jakarta Sans
* **Hosting:** Vercel

## ✨ Core Features
* **Dynamic Header:** Animated typing text effect.
* **Theme Switching:** Dark/Light mode toggle powered by JavaScript.
* **Glassmorphism UI:** Asymmetric cards and responsive grid layouts.
* **Interactive Elements:** Smooth scroll navigation and interactive project cards.
